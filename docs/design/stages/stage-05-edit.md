# stage 5 編集反映 設計メモ

## 役割
- 生成済み PPTX を入力し、書式を保持したままテキスト差分を適用する。
- 差分 JSON を指定しない場合は LLM がスライド単位で差分を生成して適用する。差分 JSON 指定時は LLM を呼び出さず適用のみ行う。

## 入力
- 必須: 対象 PPTX
- 任意: 差分 JSON（`edits` 配列 または `{"edits":[...]}`）

## 出力
- 編集済み PPTX（成果物は PPTX のみを返す）
- 内部記録: 適用した差分（applied_edits.json）を保存し、監査・再適用に利用

## 挙動
1. PPTX を読み込み、差分が指定されていればそのまま適用。未指定ならスライド単位でスナップショットを取り LLM に差分生成を依頼。
2. shape_id / slide_index / name をキーにテキスト差し替えを実施。書式（フォント・段落スタイル）を保持する。
3. 適用件数と未適用を集計し、ジョブ結果として返却。
4. 成果物（編集後 PPTX）を所定の出力ディレクトリに保存し、適用差分のログを内部ファイルに記録。

## API/CLI 挙動
- CLI: `pptx edit <pptx_path>`。`--edits-json` 指定時は LLM を呼ばず適用のみ。既定出力は `.pptx/edit/<pptx名>`。
- API: `/edit` に `pptx_path`（必須）、任意で `edits_json`/`edits` を受け付ける。成果物は `pptx_url` としてダウンロード可。

## 例外・エラー
- PPTX 不在や差分 JSON 読み込み失敗は同期 422/404 で返却する。
- LLM 呼び出し失敗はジョブを failed にし、エラーを返却する。

## テスト観点（抜粋）
- 差分指定なしで LLM が空配列でも成功すること。
- 差分 JSON 指定時は LLM を呼ばず適用されること。
- artifacts の URL が HTTP で取得可能なこと（API）。
- 差分適用失敗時にジョブが failed となり artifacts を返さないこと。
